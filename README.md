
  ----TutorOS -------

TutorOS - сервис для управления работой частного репетитора или небольших онлайн-школ. 


Планируемые возможности:

- управление учениками;
- расписание занятий;
- домашние задания;
- учёт оплат;
- учебные материалы;
- аналитика прогресса.


Стек:

-C#
-.NET 9
-WPF
-PostgreSQL
